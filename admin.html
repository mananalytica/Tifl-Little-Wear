Media library

Upload photos here once, then reuse them across products — no Cloudinary needed. Photos are stored in your Cloudflare R2 bucket (not the database); this page just keeps track of them. Uploads are hashed, so if you accidentally upload the same photo twice, it's recognised as a duplicate and reuses the original instead of storing it again.

Needs a one-time Cloudflare R2 setup first — see the comment block at the top of index.py for the exact steps and the environment variables to set in Vercel. Until that's done, uploads here will show an error.

Bulk upload (CSV or XML)

Upload a Google Shopping-style feed file to add or update many products at once. Matching is done by SKU — if a row's SKU matches an existing product, that product is updated instead of duplicated, so it's safe to re-upload the same file later.

Expected columns (CSV header row, or XML <item> tags): id, title, description, link, image_link, additional_image_link, price, sale_price, availability, brand, condition, gtin, mpn, google_product_category, product_type, color, size, material, gender, age_group, item_group_id. id is used as the SKU. For multiple extra photos, put a comma-separated list of URLs in additional_image_link. Missing columns are fine — only title and price are required.

Shopping feed URLs
