Bulk upload (CSV or XML)

Upload a Google Shopping-style feed file to add or update many products at once. Matching is done by SKU — if a row's SKU matches an existing product, that product is updated instead of duplicated, so it's safe to re-upload the same file later.

Expected columns (CSV header row, or XML <item> tags): id, title, description, link, image_link, price, sale_price, availability, brand, condition, gtin, mpn, google_product_category, product_type, color, size, gender, age_group, item_group_id. id is used as the SKU. Missing columns are fine — only title and price are required.
