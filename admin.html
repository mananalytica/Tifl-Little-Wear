Add and manage products

Anything you add or edit here appears on the Shop page immediately — no code changes needed. Fields below match the Google Merchant Center and Meta Catalog feed spec directly, so the same product data can power your website, a Google Shopping listing, and a Meta/Instagram catalogue at once. This page is not linked from the site menu and isn't indexed by search engines, but it's not hidden by a real login — don't share this URL publicly.

Bulk upload (CSV or XML)

Upload a Google Shopping-style feed file to add or update many products at once. Matching is done by SKU — if a row's SKU matches an existing product, that product is updated instead of duplicated, so it's safe to re-upload the same file later.

Expected columns (CSV header row, or XML <item> tags): id, title, description, link, image_link, additional_image_link, price, sale_price, availability, brand, condition, gtin, mpn, google_product_category, product_type, color, size, material, gender, age_group, item_group_id, stock_quantity, features. id is used as the SKU. Missing columns are fine — only title and price are required.

Multiple photos: put more than one URL in additional_image_link, separated by commas.
Features: in features, separate each feature with a | and split its title from its description with a : — e.g. Premium Jacquard Fabric: Crafted from high-quality jacquard material. | Intricate Gold Details: Adorned with delicate gold work.

Shopping feed URLs

Each platform gets its own link, so orders that come from a Pinterest tag vs a Facebook tag vs Google Shopping show up separately in the Analytics tab instead of all blurring into "direct." Give each platform its own link below — don't reuse one URL across multiple platforms, or you'll lose that distinction.

Google Merchant Center (XML):
/api/products/feed.xml?utm_source=google&utm_medium=shopping&utm_campaign=product_catalog
Meta Commerce Manager — Instagram + Facebook (CSV):
/api/products/feed.csv?utm_source=facebook&utm_medium=social&utm_campaign=product_catalog
Pinterest Catalogs (CSV):
/api/products/feed.csv?utm_source=pinterest&utm_medium=social&utm_campaign=product_catalog
Snapchat Catalog Manager (CSV):
/api/products/feed.csv?utm_source=snapchat&utm_medium=social&utm_campaign=product_catalog
YouTube Shopping, via Merchant Center (XML):
/api/products/feed.xml?utm_source=youtube&utm_medium=social&utm_campaign=product_catalog

Add and manage master tailors

Each row here becomes its own page at master-tailor.html?slug=<slug> and a card on tailors.html — no code changes needed. Tag a product to a tailor above (the "Designed / stitched by" dropdown) and it automatically shows up in that tailor's portfolio and lookbook.

Bulk upload (CSV)

Upload a CSV to add or update many tailors at once. Matching is done by URL slug — if a row's slug matches an existing tailor, that tailor is updated instead of duplicated, so it's safe to re-upload the same file later.

Expected columns: slug, name, title, tagline, photo_url, years_experience, garments_count, apprentices_count, established_year, bio, specialties, timeline, gallery, testimonials, active. Only slug and name are required. photo_url can be a real photo link or a "#hex" colour placeholder.

specialties / timeline / gallery / testimonials are optional JSON — leave a cell blank to skip that section, or paste a JSON list, e.g. [{"title":"Hand embroidery","description":"..."}] for specialties. If a spreadsheet program adds extra quoting around JSON when you export CSV, that's fine — it's parsed the same way the product bulk upload parses its columns.

Add and manage fabrics

Width and pattern repeat are what real yardage estimates are built from — worth filling in accurately for every fabric you stock. This catalog feeds the tech pack generator.

Bulk upload (CSV)

Upload a CSV to add or update many fabrics at once. Matching is done by fabric name (not case-sensitive) — if a row's name matches an existing fabric, that fabric is updated instead of duplicated, so it's safe to re-upload the same file later.

Expected columns: name, composition, width_cm, pattern_repeat_cm, drape_type, cost_per_yard, supplier, notes, active. Only name is required. drape_type should be one of crisp, structured, fluid, stretch.
